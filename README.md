# 闲鱼定时助手 · XianyuScheduler

## 当前功能

### 1. 一键擦亮

“一键擦亮”已经是独立任务卡片，不再依赖“闲鱼本地任务”。

执行流程：

```text
打开闲鱼
→ 进入“我的”
→ 点击“我发布的”
→ 进入“我的发布”
→ 点击顶部“今日数据”区域的一键擦亮
→ 返回“我的”
```

安全限制：

- 每次自动任务最多执行一次擦亮。
- 优先使用 OCR 识别“我发布的”和“一键擦亮”。
- OCR 不稳定时，只在已经确认正确页面后才允许使用实机比例坐标兜底。
- 不点击商品行里的“加曝光 / 降价 / 编辑”。
- 单独运行“一键擦亮”时，擦亮完成后不会再进入闲鱼币任务面板。

### 2. 闲鱼本地任务

用于执行**只在闲鱼 App 内完成、不跳转到其他 App**的任务。

例如当前分类逻辑中支持的本地任务关键词包括：

- 签到
- 指定频道好物
- 浏览福利好物
- 访问/领取闲鱼币
- 搜一搜 / 搜索 / 搜商品

执行时会进入：

```text
闲鱼首页
→ 我的
→ 闲鱼币
→ 得骰子 / 赚闲鱼币
→ 任务面板
→ 执行支持的本地任务
→ 验证任务结果
```

### 3. 视频任务

用于执行闲鱼任务面板中的视频类任务，例如：

- 看15秒视频领奖励
- 看视频奖励
- 观看视频领取奖励
- 视频领奖励
- 看广告

视频任务与本地任务使用独立开关，可以只运行视频任务。

### 4. 跳转任务

用于识别需要跳转到其他 App 或外部页面的任务，例如支付宝、淘宝、高德、美团等相关任务。

跳转任务有独立开关。未开启时不会主动执行这类任务。

## 已移除功能

### 小游戏任务

自 4.48.0 起，小游戏任务已从产品功能中移除：

- UI 中没有小游戏任务卡片。
- `TaskCategory.GAME` 已移除。
- 历史 `GAME` Intent 会被拒绝。
- 水果、麻将、“玩1关”“小游戏”等标题会被当作不支持任务并跳过。
- 自动/定时任务不会再进入小游戏。

旧 Solver 源码目前仅作为不可达兼容代码保留，不存在产品入口，不会被正常调度器调用。

# 怎么用

## 一、首次使用前准备

### 1. ROOT 权限

本应用依赖 ROOT 执行点击、滑动、启动 App、读取前台状态等操作。

如果首页显示 ROOT 未授权：

1. 打开 KernelSU（或当前设备使用的 ROOT 管理器）。
2. 找到“闲鱼定时助手”。
3. 开启超级用户权限。
4. 返回助手。
5. 点击 ROOT 权限卡片重新检测。

没有 ROOT 权限时，自动任务不能正常执行。

### 2. 精确定时权限

如果要使用“每日定时”，需要允许系统的精确定时/闹钟能力。

在 App 首页查看定时权限状态；如果未授权，按系统提示开启对应权限。

---

## 二、选择要运行的任务

进入底部导航中的 **“自动化”** 页面。

当前有 4 个独立开关：

```text
一键擦亮
闲鱼本地任务
视频任务
跳转任务
```

开关之间互不绑定。

例如：

### 只想每天擦亮商品

只开启：

```text
✅ 一键擦亮
❌ 闲鱼本地任务
❌ 视频任务
❌ 跳转任务
```

执行时只会：

```text
我的 → 我发布的 → 一键擦亮 → 返回
```

### 只想做闲鱼内部任务

开启：

```text
❌ 一键擦亮（按需）
✅ 闲鱼本地任务
❌ 视频任务
❌ 跳转任务
```

### 全部一起执行

可以同时开启多个卡片。

组合执行时顺序为：

```text
一键擦亮
→ 闲鱼本地任务
→ 视频任务
→ 跳转任务
```

---

## 三、立即执行

在“自动化”页面选择好卡片后，点击 **“执行任务”**。

如果只开启一个卡片，程序只运行该分类。

如果同时开启多个卡片，程序按已开启的卡片顺序执行。

运行过程中，日志页会显示：

- 当前前台 App
- 页面识别结果
- 点击/返回操作
- 任务是否验证成功
- 是否触发人工接管
- 是否因为锁屏、页面异常等原因停止

---

## 四、每日定时

在“自动化”页面找到 **“每日定时”**。

操作方法：

1. 先打开你希望每天执行的任务卡片。
2. 点击 **“设置时间”**。
3. 选择每天执行的时刻。
4. 保存后，状态会显示每日定时已启用。

到点时程序会读取**当时仍然开启的任务卡片**并执行。

例如设置每天 09:00，同时开启“一键擦亮”和“闲鱼本地任务”，则每天大致按：

```text
09:00 定时触发
→ 唤醒屏幕
→ 检查锁屏
→ 启动/切回闲鱼
→ 一键擦亮
→ 闲鱼本地任务
→ 返回助手
```

需要停止定时，点击 **“取消定时”**。

# 息屏和锁屏说明

这是使用定时任务时最重要的一点。

## 只是息屏，没有安全锁屏

可以自动执行。

当前逻辑会：

```text
定时触发
→ ROOT 发送 KEYCODE_WAKEUP
→ 点亮屏幕
→ 检查 Keyguard
→ 未锁屏
→ 启动闲鱼
→ 执行任务
```

所以手机可以熄屏，不要求屏幕一直亮着。

## 手机已经进入密码/PIN/图案锁屏

当前版本**不会自动输入锁屏密码，也不会绕过安全锁屏**。

检测到 `KeyguardManager.isKeyguardLocked()` 后会停止本轮任务，并记录类似：

```text
设备锁屏，无法执行 UI 自动化
```

因此如果这是一台专门用于自动任务的设备，推荐：

- 可以允许自动息屏；
- 但不要让设备进入需要 PIN/密码/图案才能解锁的安全锁屏。

这样定时任务才能真正做到无人值守。

# 人工接管

自动任务运行期间，如果检测到真实手指操作，程序会停止自动点击，避免和用户抢屏幕。

ROOT 产生的程序点击/滑动会被识别为合成输入，不应被当成真人接管。

如果你主动切回助手 App，也会被视为结束/接管当前自动流程。

---

# 任务记录与日志

底部导航提供：

### 任务记录

只统计已经验证为 SUCCESS 的任务。

失败、未验证、人工中止不会计入完成数。

### 日志

用于排查实机问题，建议出现异常时保留完整日志。

重点日志通常包括：

```text
[调度]
[执行]
[极速导航]
[一键擦亮]
[验证]
[人工检测]
[完成]
```

如果需要排查某个任务，最好同时提供：

1. 对应版本号；
2. 完整 `xianyu_log.txt`；
3. 从任务开始到异常出现的完整录屏。

---

# 推荐使用方式

如果主要目标是稳定无人值守，可以采用：

```text
ROOT 已授权
+ 精确定时权限已开启
+ 手机允许息屏但不进入安全锁屏
+ 只开启实际需要的任务卡片
+ 设置每天固定时间
```

这样定时到点后，助手会自动唤醒屏幕、启动闲鱼并执行已经开启的任务。
