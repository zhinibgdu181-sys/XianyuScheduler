# 闲鱼定时助手 · XianyuScheduler

## 当前功能

### 手势细节学习

首页状态卡改为“手势细节学习”。点击卡片开始后，助手本身不会自动点击；切到闲鱼后按平时方式操作即可。

这里**不手势细节学习做任务的完整流程**，也不学习“先点哪里、后点哪里”的页面顺序。

只学习单次手势的动作风格：点击时的微小落点变化、按压时长，以及滑动的完整相对轨迹、抖动、弧度、滑动距离和速度变化。保存的轨迹以触摸起点为相对坐标，不保存原始页面点击位置，也不记录相邻操作顺序。

已经积累真人样本后，任务识别和执行顺序仍由程序自己的规则决定；真人样本只影响“怎么点、怎么滑”。自动点击会在识别到的目标附近做小幅安全偏移，不会每次落在完全相同的像素；自动滑动会在任务允许范围内参考已学习的滑动距离、曲线、抖动和速度。开始自动任务时会暂停学习，避免程序输入污染真人样本。


### 1. 一键擦亮

“一键擦亮”已经是独立任务卡片，不再依赖“闲鱼本地任务”。

执行流程：

```text
打开闲鱼
→ 进入“我的”
→ 点击“我发布的”
→ 进入“我的发布”
→ 点击顶部“今日数据”区域的一键擦亮
→ 返回“我的”
```

安全限制：

- 每次自动任务最多执行一次擦亮。
- 优先使用 OCR 识别“我发布的”和“一键擦亮”。
- OCR 不稳定时，只在已经确认正确页面后才允许使用实机比例坐标兜底。
- 不点击商品行里的“加曝光 / 降价 / 编辑”。
- 单独运行“一键擦亮”时，擦亮完成后不会再进入闲鱼币任务面板。

### 2. 闲鱼本地任务

用于执行**只在闲鱼 App 内完成、不跳转到其他 App**的任务。

例如当前分类逻辑中支持的本地任务关键词包括：

- 签到
- 指定频道好物
- 浏览福利好物
- 访问/领取闲鱼币
- 搜一搜 / 搜索 / 搜商品

执行时会进入：

```text
闲鱼首页
→ 我的
→ 闲鱼币
→ 得骰子 / 赚闲鱼币
→ 任务面板
→ 执行支持的本地任务
→ 验证任务结果
→ 同一任务出现“领取奖励”时立即领取闲鱼币
```

任务完成后的奖励领取是通用逻辑：本地任务、视频任务、小游戏任务只要已经验证完成，并且任务面板出现该任务对应的“领取奖励”，程序都会优先点击领取。不会因为看到其它位置的“领取奖励”文字就盲点。

### 3. 视频任务

用于执行闲鱼任务面板中的视频类任务，例如：

- 看15秒视频领奖励
- 看视频奖励
- 观看视频领取奖励
- 视频领奖励
- 看广告

视频任务与本地任务使用独立开关，可以只运行视频任务。

### 4. 小游戏任务

用于识别需要跳转到其他 App 或外部页面的任务，例如支付宝、淘宝、高德、美团等相关任务。

小游戏任务有独立开关。未开启时不会主动执行这类任务。

## 已移除功能

### 小游戏任务

小游戏现在作为独立任务分类：

- UI 中有独立“小游戏任务”开关。
- `TaskCategory.GAME` 专门负责水果、麻将、消除类等小游戏任务。
- 自动任务按“闲鱼本地 → 视频 → 小游戏”的分类顺序执行已开启项目。
- 小游戏不会混入闲鱼本地任务，也不会作为外部跳转任务处理。

旧 Solver 源码目前仅作为不可达兼容代码保留，不存在产品入口，不会被正常调度器调用。

# 怎么用

## 一、首次使用前准备

### 1. ROOT 权限

本应用依赖 ROOT 执行点击、滑动、启动 App、读取前台状态等操作。

如果首页显示 ROOT 未授权：

1. 打开 KernelSU（或当前设备使用的 ROOT 管理器）。
2. 找到“闲鱼定时助手”。
3. 开启超级用户权限。
4. 返回助手。
5. 点击 ROOT 权限卡片重新检测。

没有 ROOT 权限时，自动任务不能正常执行。

### 2. 精确定时权限

如果要使用“每日定时”，需要允许系统的精确定时/闹钟能力。

在 App 首页查看定时权限状态；如果未授权，按系统提示开启对应权限。

---

## 二、选择要运行的任务

进入底部导航中的 **“自动化”** 页面。

当前有 4 个独立开关：

```text
一键擦亮
闲鱼本地任务
视频任务
小游戏任务
```

开关之间互不绑定。

例如：

### 只想每天擦亮商品

只开启：

```text
✅ 一键擦亮
❌ 闲鱼本地任务
❌ 视频任务
❌ 小游戏任务
```

执行时只会：

```text
我的 → 我发布的 → 一键擦亮 → 返回
```

### 只想做闲鱼内部任务

开启：

```text
❌ 一键擦亮（按需）
✅ 闲鱼本地任务
❌ 视频任务
❌ 小游戏任务
```

### 全部一起执行

可以同时开启多个卡片。

组合执行时顺序为：

```text
一键擦亮
→ 闲鱼本地任务
→ 视频任务
→ 小游戏任务
```

---

## 三、立即执行

在“自动化”页面选择好卡片后，点击 **“执行任务”**。

如果只开启一个卡片，程序只运行该分类。

如果同时开启多个卡片，程序按已开启的卡片顺序执行。

运行过程中，日志页会显示：

- 当前前台 App
- 页面识别结果
- 点击/返回操作
- 任务是否验证成功
- 是否触发人工接管
- 是否因为锁屏、页面异常等原因停止

---

## 四、每日定时

在“自动化”页面找到 **“每日定时”**。

操作方法：

1. 先打开你希望每天执行的任务卡片。
2. 点击 **“设置时间”**。
3. 选择每天执行的时刻。
4. 保存后，状态会显示每日定时已启用。

到点时程序会读取**当时仍然开启的任务卡片**并执行。

例如设置每天 09:00，同时开启“一键擦亮”和“闲鱼本地任务”，则每天大致按：

```text
09:00 定时触发
→ 唤醒屏幕
→ 检查锁屏
→ 启动/切回闲鱼
→ 一键擦亮
→ 闲鱼本地任务
→ 返回助手
```

需要停止定时，点击 **“取消定时”**。

# 息屏和锁屏说明

这是使用定时任务时最重要的一点。

## 只是息屏，没有安全锁屏

可以自动执行。

当前逻辑会：

```text
定时触发
→ ROOT 发送 KEYCODE_WAKEUP
→ 点亮屏幕
→ 检查 Keyguard
→ 未锁屏
→ 启动闲鱼
→ 执行任务
```

所以手机可以熄屏，不要求屏幕一直亮着。

## 手机已经进入密码/PIN/图案锁屏

当前版本**不会自动输入锁屏密码，也不会绕过安全锁屏**。

检测到 `KeyguardManager.isKeyguardLocked()` 后会停止本轮任务，并记录类似：

```text
设备锁屏，无法执行 UI 自动化
```

因此如果这是一台专门用于自动任务的设备，推荐：

- 可以允许自动息屏；
- 但不要让设备进入需要 PIN/密码/图案才能解锁的安全锁屏。

这样定时任务才能真正做到无人值守。

# 人工接管

自动任务运行期间，如果检测到真实手指操作，程序会停止自动点击，避免和用户抢屏幕。

ROOT 产生的程序点击/滑动会被识别为合成输入，不应被当成真人接管。

如果你主动切回助手 App，也会被视为结束/接管当前自动流程。

---

# 任务记录与日志

底部导航提供：

### 任务记录

只统计已经验证为 SUCCESS 的任务。

失败、未验证、人工中止不会计入完成数。

如果“领取奖励”所在任务行能够明确识别出奖励数值，例如“+30闲鱼币”，会把该数值记录到对应任务，并汇总到当天闲鱼币合计。奖励数字识别不明确时只领取，不猜测、不虚报币数。

### 日志

用于排查实机问题，建议出现异常时保留完整日志。

重点日志通常包括：

```text
[调度]
[执行]
[极速导航]
[一键擦亮]
[验证]
[人工检测]
[完成]
```

如果需要排查某个任务，最好同时提供：

1. 对应版本号；
2. 完整 `xianyu_log.txt`；
3. 从任务开始到异常出现的完整录屏。

---

# 推荐使用方式

如果主要目标是稳定无人值守，可以采用：

```text
ROOT 已授权
+ 精确定时权限已开启
+ 手机允许息屏但不进入安全锁屏
+ 只开启实际需要的任务卡片
+ 设置每天固定时间
```

这样定时到点后，助手会自动唤醒屏幕、启动闲鱼并执行已经开启的任务。

# 当前版本摘要

**4.48.2**

- 一键擦亮改为独立卡片。
- 独立开关：擦亮 / 本地 / 视频 / 跳转。
- 支持立即执行和每日定时。
- 定时触发时可从普通息屏状态自动唤醒。
- 安全锁屏状态下停止执行，不保存或自动输入密码。
- 小游戏已恢复为独立任务分类，与本地、视频任务隔离。


## 4.49.0 任务完成后自动领取奖励

- 本地、视频、小游戏任务在“任务完成已验证”后，立即检查同一任务行是否出现“领取奖励”。
- 只有 OCR 能把“领取奖励”按钮与刚完成的同一任务绑定时才点击，不使用固定坐标盲点。
- 最多短暂复查 4 次；如果按钮暂时还没刷新出来，后续任务面板正常扫描仍会继续识别并领取。
- 原有“领取奖励”候选逻辑继续作为兜底，因此已经完成但尚未领取的任务也可以被补领。
- 领取动作本身会再次验证“已领取 / 领取成功 / 按钮消失”等状态。
- 如果任务行明确显示“+N闲鱼币 / N闲鱼币 / 闲鱼币×N”，在领取验证成功后才记录该奖励。
- 同一任务重复 OCR 或重复验证不会重复累计同一笔奖励。
- 任务记录页面会在任务后显示已确认奖励，并显示当天已确认闲鱼币合计。
- 无法可靠识别奖励数值时仍然执行领取，但币数不猜测、不计入合计。
- “一键擦亮”只是发布商品维护动作，不进入“领取奖励”流程，也不计入闲鱼币收益。


## 4.50.0 实机问题整改

- 启动/切回闲鱼后，所有任务之前先检查启动广告；识别到“跳过广告/跳过N”时优先点击，避免一键擦亮把广告页当成未知页面。
- 一键擦亮在“我的”页对“我发布的”做子文本定位；即使 OCR 把“我发布的 / 我的空间 / 我卖出的”合并成一行，也不再点击整行中心。
- “点击指定频道好物”不再只接受“抵30%...”开头的商品标题；普通商品标题也可作为候选，避免剩余 1 个商品时卡住。
- “浏览福利好物”只要任务倒计时/小黄鱼浮层仍存在就继续有效滑动，不再到 15 秒后原地等待。
- “领取奖励”增加同一行几何绑定，并排除“第2天 / 今天 / 任务奖励”等装饰文字作为任务名；绑定不明确时不盲点。
- 一键擦亮继续不参与闲鱼币领取和收益统计。


## 4.50.1 真人学习范围收紧

- “手势细节学习”只学习单次点击/滑动的动作风格，不学习完整任务流程、页面顺序或点击目标。
- 新版样本只保存相对轨迹（dx/dy/time），不保存原始绝对屏幕坐标；4.50.0 的旧绝对坐标样本不再复用。
- 人工接管自动任务时只负责硬停止，不再自动进入任何“真人流程教学”。
- 自动点击在识别目标附近加入小幅、受限的落点变化，同时保留学习到的按压时长和微抖动。
- 自动滑动会参考学习到的滑动距离、弧度、抖动和速度，并加入轻微的起点/终点变化；仍受原任务动作范围约束。


## 手势学习与任务流程彻底分离

- 删除旧的任务流程教学逻辑；人工接管只负责停止自动化。
- 手势学习只保存单次点击/滑动动作特征，不保存页面顺序、任务步骤或完成流程。
- 自动任务期间检测到真人触摸只执行硬停止，不启动任何后台教学窗口。
- TaskForegroundService 不再等待真人教学结束；任务执行器一结束就释放前台服务，避免下一次任务被误判为“已有运行实例”。
- 独立“手势细节学习”卡片保持不变，只学习单次点击/滑动的动作风格。


## 4.50.3 自动化页面与任务分类修正

- 自动化页面改为可纵向滚动，底部“执行任务 / 立即执行”卡片不再被底部导航栏挤压或遮挡。
- 增加页面底部留白，较小屏幕也可以完整滚动到“立即执行”按钮。
- “逛逛商城领超值优惠券”明确归入闲鱼本地任务，不再因为“逛逛”关键字被误分到小游戏任务。


## 4.50.4 自动化单屏布局

- 撤销自动化页面滚动，恢复固定单屏操作。
- 每日定时压缩成一行状态区，设置时间/取消定时放在右侧。
- 一键擦亮、本地、视频、跳转四张任务卡片采用等高弹性分布，减少卡片间距和内边距。
- “执行任务”固定在四类任务下方、底部导航上方，始终完整显示“立即执行”按钮。
