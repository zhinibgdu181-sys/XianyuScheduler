# 闲鱼定时助手 · XianyuScheduler

这是一个从干净仓库重新整理的版本。

## 保留部分
- 原有 UI 页面与底部导航
- 定时任务与自动任务调度
- 本地任务、视频任务、滑动/浏览任务
- ROOT 执行与任务状态验证
- 任务完成后的受控返回流程

## 新小游戏架构
水果小游戏不再继续维护旧的巨型决策类，而是拆成：

`截图 → 全棋盘视觉识别 → 不可变状态 → 状态搜索 → 单步执行 → 截图验证 → 立即重新规划`

每次点击后都重新建立当前棋盘状态；首击没有状态变化时直接废弃该候选并重新识别，不进入长时间“无动作”等待。弹窗关闭后同样立即重建棋盘。

当前阶段重点是先保证 UI/自动任务基线稳定，再继续用真实运行日志校准水果视觉识别与搜索参数。


## 4.45.0 水果求解器整改
- 棋盘识别区域重新按真实游戏画面校准：包含顶部水果，排除屋顶下方按钮区。
- 槽位只在屋顶中央收集区识别，不再把整条底部 UI 当作槽位。
- 水果外观距离加入小范围平移容差，降低同类水果因中心点漂移被判成不同类的概率。
- Planner 增加同类候选/最近邻诊断日志，出现“无安全动作”时可直接判断是视觉还是规划问题。
- 真实手指触摸只触发硬停止；不再启动真人教学窗口，不记录 TAP/SWIPE/WAIT，不回放真人操作。
- 保留“截图 → 识别 → 搜索 → 单组执行 → 截图验证 → 重规划”的闭环。


## 4.45.1 热修复
- 修复大量候选配对时 Planner 近似 O(n³) 导致搜索预算在 DFS 前耗尽、最终错误返回“无安全动作”。
- 配对距离与最近邻一次性预计算，候选动作限制为最高分 48 组；搜索超时仍回退到最佳根配对。
- 暂停把屋顶/装饰区域当成槽位占用，视觉槽位状态未知时不再伪报 tray=4。
- 增加水果页面状态机：复活、继续玩、开始游戏、功能弹窗和任务面板均优先处理，禁止把弹窗/任务面板送入水果识别。
- 删除“去完成”造成的假通关判断；只有明确的任务完成/过关/下一关文本才作为完成证据。
- 点击后一旦 OCR 已回任务面板，立即停止水果求解，不再把任务面板识别成 70+ 个水果。
